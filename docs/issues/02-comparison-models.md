# 02 — 비교 모델과 주장 범위

담당 범위: 무엇과 비교할 것인가, 그 비교가 무엇을 증명하고 무엇은 증명하지
못하는가. 숫자 종합은 `docs/status_4x4.md`.

## 확정된 것 — 다시 논의하지 말 것

### 이 해밀토니안은 stoquastic 입니다

`J` 는 대각항에만 들어가고 비대각 원소는 전부 `-h < 0` 이므로 **어떤 `J` 에서도**
부호 문제가 없습니다 (`ea_bimodal`/`gaussian`/`villain` × 시드 4개 확인: 최대
비대각 `+0.000`, 양의 비대각 0개, frustration 은 항상 존재). Perron–Frobenius
로 바닥상태 진폭이 전부 음이 아니므로 **QMC 로 고전 샘플링 가능**합니다
(최소 진폭 `+4.04e-03`).

- **frustration ≠ 부호 문제.** "부호 문제 때문에 고전적으로 어렵다" 고 쓰면
  틀립니다. 이미 제거했습니다.
- **목표 3은 "고전 불가능" 주장이 아닙니다.** QMC 는 `|ψ₀(x)|²` 표본과 에너지를
  줄 뿐 `|ψ_GS⟩` 를 주지 않고, 그 출력을 다음 양자 회로에 넣을 방법이 없습니다.
  → **QMC 는 경쟁자가 아니라 기준값 제공자**입니다. ED 가 없는 100큐비트에서
  장치를 검증할 유일한 수단이고, 이건 큰 이점입니다.
  → **경쟁자는 단열 Trotter / VQE / QITE** — 같은 결과물(레지스터 안의 상태)을
  내놓는 방법들이고, 여기에 대고 **깊이**를 비교합니다.
  → "QMC 가 못 한다" 는 **결과물의 형태**에 대한 말이지 계산 난이도가 아닙니다.
  섞지 마세요. 그리고 QMC 출력을 이용하는 고전-보조 준비 기법이 있을 수 있으므로
  **"QMC 단독으로는 레지스터 상태를 주지 않는다"** 로 좁게 쓰세요.

### 시간 진화된 상태는 다릅니다

바닥상태는 진폭이 전부 양수지만 시간 진화된 상태는 위상이 `2π` 에 퍼집니다.
"비트스트링 샘플링이 우위가 아니다" 는 **바닥상태 분포**에 대한 말이고, 목표 2의
샘플링은 **시간 진화된 상태**에서 이뤄집니다. 어려움은 "샘플링" 이라는 행위가
아니라 **어떤 상태를 샘플링하느냐**에 있습니다.

### iPEPS 는 넣지 않기로 했습니다

비교는 ED, SPD, Trotter circuit Pauli propagation.

### 규모별로 무엇을 주장할 수 있나

| 규모 | 고전 참값 | 가능한 주장 |
|:--|:--|:--|
| 4×4 | ED 완전 | 정확도·깊이 우위를 **증명** |
| 7×7 | 없음 | 샘플링 품질, 자기수렴 |
| 10×10 | 없음 | 국소 관측량 일치, 에너지 보존, 바닥에너지 |

## 목표 3 경쟁자 곡선 — 측정 완료 (2026-09-03, RUNBOOK 1b)

세 경로가 **같은 게이트 알파벳**(큐빗마다 RX, 결합마다 RZZ)을 쓰므로 한 층은
어느 경로에서나 24개의 2Q 이고, **층수를 맞추는 것 = 2Q 를 맞추는 것**입니다.
차이는 **각도를 무엇이 정하느냐**뿐입니다.

독립 재계산으로 확인했습니다(생산 코드 미사용, 희소 kron): ED 는 `5e-14`,
단열 6행 재평가는 `<1.5e-14`, `best_T_A` 는 `M=32` 재스캔에서 동일,
BP-PPS 바닥상태 각도의 실제 회로 에너지 `-21.999320` (보고값과 `4.7e-6`).
**단열 곡선과 ED 는 신뢰할 수 있습니다.**

### 주장은 두 층위로 갈라야 합니다

`03f` 의 HVA 행은 **statevector 최적점이지 배포 가능한 회로가 아닙니다.**
BP-PPS 로 훈련해 각도를 손에 쥔 것은 `L=3` 하나뿐입니다 (`L=5` 는 41시간 뒤
중단, 각도 폐기). **인용할 때마다 층위를 밝히세요.**

**층위 B — 배포 가능 (대표 문장은 이쪽)**

| | 2Q | `dE` | `F` |
|:--|--:|--:|--:|
| BP-PPS HVA `L=3` | **72** | 0.4729 | 0.7211 |
| 같은 에너지의 VQE | 129 | | |
| 같은 에너지의 단열 | **1,081** | | |

→ **단열 15.0배, VQE 1.8배.** 둘 다 측정 구간 안의 보간 — 외삽 없음.
fidelity 로 맞춰도 13.7 / 1.8 배로 같은 그림입니다.

**층위 A — 안수 상한 (배포 불가)**: HVA `L=5` 120 2Q, `dE`=0.0419, `F`=0.986
→ VQE 442, 단열 12,943 (3.7배 / 108배). **둘 다 측정 범위 밖 외삽이라 이대로
인용하면 안 됩니다.**

> ⚠️ **상한 곡선은 `gs_competitors.json` 이 아니라 두 실행의 최솟값입니다.**
> 같은 안수·해밀토니안·`|+…+⟩` 를 두 스크립트가 각각 최적화했는데 값이 다릅니다
> (`03_statevector_pilot.py` Trotter warm start 600초 대 `03f` 무작위 300초).
> **`L≥3` 에서 pilot 이 전부 이깁니다** (`L=8`: `dE` 0.0135 대 0.0443, 3.3배).
> 둘 다 하한이므로 `L` 마다 더 좋은 쪽을 씁니다. **`03f` 의 HVA 행만 보고
> "안수의 한계" 라고 쓰면 안수를 과소평가합니다.**

**외삽이 전혀 없는 문장 — 논문에는 이 형태로:**

> 측정한 가장 깊은 단열은 `M=100`, 2,400 2Q 에서 `dE=0.210`, `F=0.860` 이다.
> HVA 는 `L=4`, **96 2Q** 에서 `dE=0.145`, `F=0.912` 로 두 지표 모두 낫다 —
> **25배 적은 게이트로.** 가장 깊은 VQE 는 `p=12`, 288 2Q 에서 `dE=0.098`;
> HVA 는 `L=5`, **120 2Q** 에서 `dE=0.042` 로 앞선다 — **2.4배 적게.**

### 지수가 다른 것이 진짜 결과입니다

`dE ~ (2Q)^-α` 를 48 2Q 이상에서 맞추면 **HVA 3.69 / VQE 1.78 / 단열 0.92**.
단열의 0.92 는 선형 스케줄에서 기대되는 `1/M` 그 자체입니다. 배수가 정확도를
올릴수록 커지는 것(8.7 → 14.5 → 28.5 → 50.8배)은 상수 배가 아니라 **지수
차이**에서 옵니다. 다만 HVA 의 α 는 6점 적합이고 `L≥10` 은 못 믿으므로
**"기울기가 다르다" 까지가 지금 지지되는 문장**이고 구체적 지수는 잠정입니다.

### 인용할 때 반드시 같이 적을 것

1. **깊은 행은 최적화가 잘려 있습니다.** `HVA L≥3`, `VQE p≥8` 이 전부 300초
   상한(`maxiter=300` 미달). `HVA L=12` 가 `L=8` 보다 나쁜 것은 안수가 아니라
   이 상한입니다. VQE 도 덜 최적화됐으므로 **배수는 우리에게 유리한 쪽으로
   치우쳐 있습니다.**
2. **단열은 경쟁자의 가장 약한 판본입니다** (아래 SOTA 절).
3. **`gs_competitors.json` 에 각도가 없습니다.** 목표 3의 주장이 "레지스터 안의
   상태" 인 이상 경쟁자 회로를 복원할 수 없다는 건 재현성 구멍입니다. 단열은
   스케줄에서 복원되지만 VQE·HVA 는 불가능합니다.
4. ED 갭이 `0.0319` 이므로 층위 A 의 `dE=0.042` 는 아직 갭보다 큽니다 —
   아래 축퇴 항목과 같이 읽을 것.

### 첫 RX 층은 죽어 있습니다 (세 경로 전부)

`|+…+⟩` 에서 RX 는 위상만 바꾸므로 **1층의 RX 16개는 어떤 값이어도 같습니다.**
`gs_trained_params.json` 의 앞 16개 각도가 warm start `-1/3` 에서 한 번도
안 움직였고 gradient 가 정확히 0 입니다. BP-PPS `L=3` 의 유효 파라미터는
120개가 아니라 **104개**입니다. VQE 도 `beta_0` 를 바꿔도 겹침 `1.000000000000`.

따라서 회로가 `RX → RZZ` 순서라 **`p` 층 VQE 는 비용층 `p` + 믹서 `p-1`** 입니다
(독립 구현과 겹침 `1.000000000000`). 꼬리에 RX 를 붙이면 2Q 비용 0 으로 세
변분 경로 모두 표현력이 커집니다.

> **결정 (사용자, 2026-09-03): 믹서는 그대로 둡니다.** 세 경로가 똑같이 손해를
> 보고 있어 방향성 편향이 아니고, 회로를 바꾸면 훈련된 `L=3` 과 비교 기준이
> 어긋납니다. 기록으로만 남기고 실험하지 않습니다.

## 이름: 경쟁자는 VQE 입니다 (2026-09-03 결정)

회로 모양만 QAOA 이고 **최소화 대상은 횡자기장을 포함한 `H`** 라 목표물이
비트스트링이 아닙니다. 표에 QAOA 라고 쓰면 리뷰어를 틀린 문헌으로 보냅니다.
**`gs_competitors.json` 의 키는 `qaoa` 그대로 — 데이터 파일은 사후에 고치지
않습니다. 키 `qaoa` == 문서의 VQE 행.**

우리 안수는 계속 **HVA**. 층당 40 자유각이라 문헌의 multi-angle QAOA
(Herrman et al., *Sci. Rep.* **12**, 6781 (2022)) 와 같은 파라미터화이고,
**"HVA 가 VQE 를 이긴다" 는 그 문헌이 이미 보고한 다중각 대 단일각 결과와
같은 크기**입니다. 새 결과로 주장하면 안 됩니다.

## 두 경쟁자는 SOTA 가 아닙니다

**정직한 교과서 기준선**이지 최신 최고 성능이 아닙니다. "경쟁자 대비 N배" 라고만
쓰면 과장입니다.

**단열.** 표준 개선은 **counterdiabatic(CD) 구동**이고 Ising 계열에 정착돼
있습니다 (Hegade et al., *PRApplied* **15**, 024038 (2021); DCQO, *PRR* **4**,
L042030 (2022); 2024–2026 BF-DCQO). **위험한 점**: TFIM 의 1차 CD 항은
`Σ_i α_i Y_i` 로 **1큐빗 회전**이라 우리 통화(2Q)에서 값이 **0** 입니다. 즉
CD 단열은 같은 2Q 비용에서 더 좋아집니다. ⛔ **15배·25배가 얼마나 줄어드는지
재기 전에는 "단열 대비" 문장을 최종본에 넣지 마세요.** 2차 항(`Y_iZ_j`)부터는
2Q 를 쓰므로 그때는 공정한 대결입니다.

**VQE.** QAOA 형 안수의 본령은 대각 비용함수입니다. **양자** 해밀토니안의
바닥상태 준비에서 진짜 계열은 ADAPT-VQE / AVQITE, QITE, 소산 냉각입니다.
특히 **AVQITE 는 유한 자기장 TFIM 에서 CNOT 수가 `N` 에 선형이고 계수가 HVA 의
절반**이라고 보고돼 있어 **우리 안수를 직접 겨냥**합니다 — 최소한 인용하고 왜
비교하지 않았는지 적어야 합니다. (방어선: ADAPT 계열은 연산자 풀 탐색에
하드웨어 측정이 필요해 "고전에서 훈련해 배포한다" 는 우리 설정과 전제가 다릅니다.)

**가장 중요한 선행연구.** Lin, Gharibyan, Su, *Utility-Scale Quantum State
Preparation: Classical Training using Pauli Path simulation*,
**Quantum 10, 2014 (2026)** (arXiv:2510.02428). 프로그램이 우리와 같습니다 —
파울리 경로로 회로를 **고전 훈련해** 하드웨어에 올립니다. 100+ 큐비트, 2D
정사각·heavy-hex Ising 과 Kitaev honeycomb, H2 에서 48큐비트, 오차완화 없이
상대 에너지 오차 약 5%.

방법은 다릅니다 (arXiv v1 본문, 2026-09-03 확인): gradient 를 **SPSA** 로
추정하고 역전파를 쓰지 않으며, 안수는 층당 3각(`u_Z, u_X, u_ZZ`)짜리 정통 HVA,
절단 `1e-3`(최종 `1e-4`). 우리는 해석적 역전파(BP-PPS), 층당 40각, `1e-6`~`1e-7`.

→ **"고전 훈련 + 얕은 회로 배포" 자체는 더 이상 새롭지 않습니다.** 다만 그
연구는 **무질서가 없습니다.** 우리 차별점은 (a) 무질서 스핀 유리, (b) 결합마다
각도를 주어 무질서를 흡수한다는 **메커니즘** 주장입니다. 그래서 **RUNBOOK 2-3
(시드 스윕)이 "값싼 보너스" 에서 "논문의 차별점" 으로 올라갑니다.**

## T3 (10×10) 비교 방법 — 보류 중, 방향만

1. **에너지 보존.** `<H>` 는 정확히 보존되고 곱상태에서 `E(0)` 는 해석적으로
   압니다. 초기 상태를 바꿔 가며 `|E(T)-E(0)|` 을 재면 **어떤 크기에서도 고전
   참값 없이** 회로 품질을 잽니다. 2×2 스모크: `T=0.5` 6.9e-13, `T=2.0` 2.7e-3.
2. **SPD 자기수렴 스윕.** δ 를 조여 관측량이 붙는지 봅니다. 붙지 않기 시작하는
   `T` 가 `t*` 의 추정치입니다.

> **열린 질문 (사용자 확인 대기): SPD 자기수렴의 수학적 근거.** "δ→0 수렴이면
> 참값" 이 언제 성립하는지. 절단이 계통 편향을 만들면 δ 를 조여도 **틀린 값에
> 붙을 수 있습니다.**

  결정됩니다. ⛔ 목표 3 대표 문장의 전제.
- **`03f` 가 각도를 저장하도록 수정.** 지금은 경쟁자 회로를 복원할 수 없습니다.
  2-6 을 돌릴 때 같이 들어가야 합니다.
- **AVQITE 를 인용하고 왜 비교하지 않았는지 적을 것.**
- T2 에서 "샘플링이 잘 된다" 를 무엇으로 보일 것인가. ED 가 없어 분포 비교가
  불가능합니다. 주변 분포? cross-entropy benchmarking?
- **반집중과 인증 가능성의 충돌.**
  - **훈련 쪽은 문제없습니다.** no-go 계열은 손실을 **측정 샘플로 추정**하는
    모형에 대한 것입니다. BP-PPS 는 하이젠베르크 그림에서 손실·기울기를
    **해석적으로** 계산하므로(Eq. 21) 샷 노이즈도 분포 추정도 없습니다.
    게다가 `L_XZ` 는 단일 사이트 관측량의 합이라 국소 손실이고, 국소 손실은
    얕은 회로에서 barren plateau 가 훨씬 약합니다.
  - **인증 쪽이 진짜 문제입니다.** 목표 1의 검증은 **국소 관측량** 일치뿐인데
    목표 2의 주장은 **전역 비트스트링 분포**입니다. 반집중 영역에서는 단일
    사이트 `X`·`Z` 를 모두 맞히면서 전역 분포가 크게 다른 상태가 얼마든지
    있습니다. Bermejo-Vega et al. 의 "efficiently certifiable" 은 특정 족
    (IQP/Ising)에 대한 증명이지 훈련된 근사 회로에 옮겨지지 않습니다.
    → 목표 2를 주장하려면 국소 관측량 위에 무엇을 얹을지 정해야 합니다.
  - 확인 필요: *Limits of quantum generative models* (arXiv:2512.24801) 의
