## 2. 두 갈래로 다시 보기 (2026-09-04, 사용자 제안 — 채택)

목표 번호를 버리고 **시간 진화 / 바닥상태 준비** 두 갈래로 놓으면 그림이
훨씬 선명해집니다. **두 갈래의 고장 방식이 정확히 반대입니다.**

| | **시간 진화** | **바닥상태 준비** |
|:--|:--|:--|
| 손실함수 | `L_XZ` — **미리 만든 타겟 SPO 와의 거리** | `⟨H⟩` — **자기충족적** |
| 정답 데이터 | 필요. `T>0.5` 에서 못 만듦 (**타겟의 벽**) | **필요 없음** ← 사용자 지적 |
| 고전 비용을 정하는 것 | 타겟 생성 (1.2M 항). 훈련기가 아님 | 안수 깊이와 magic 뿐 |
| 100큐비트 검증 수단 | **없음** (ED 없음, QMC 는 동역학에서 무력) | **QMC + DMRG** 둘 다 있음 |
| 손실값을 믿을 수 있나 | **예.** `L_XZ ≥ 0`, 절단해도 거리는 거리 | **아니오.** 절단된 `⟨H⟩` 는 참 바닥에너지 **아래로 내려갑니다** (2510.02428) |
| 물리가 고전적으로 어려운가 | **예.** 복소 위상 + 부피법칙 얽힘 | **아니오.** stoquastic 이면 QMC, 2D 바닥상태면 DMRG/PEPS |
| 지금 상태 | `T1-T` stage 1 **취소**, 10×10 `F`=0.013 | 4×4 **완료**, 단열 15.0배 / VQE 1.8배 측정 |

한 줄로:

> **시간 진화는 주장이 강하고 실행이 막혔습니다. 바닥상태는 실행이 되는데
> 주장이 약합니다.**

사용자의 제안 = "실행되는 쪽(바닥상태)의 약한 주장을 `Y` 로 고치자". 전략의
방향은 옳습니다. 아래 §3 이 왜 그래도 안 되는지, §4 가 그럼에도 무엇이
남는지, §7 이 대신 무엇을 할지입니다.

### 먼저 짚을 것 — "타겟이 없다" 는 공짜가 아닙니다

정답 데이터를 안 만드는 대가로 **손실값의 신뢰성**을 내줍니다. `L_XZ` 는
정의상 음이 아니고 0 에 가까울수록 좋다는 뜻이 명확합니다. 반면 절단된 PPS
에너지는 변분 상한이 **아니어서**, `⟨H⟩` 가 낮게 나온 것이 회로가 좋아서인지
절단이 심해서인지 손실만 보고는 알 수 없습니다 (2510.02428 이 명시:
`gx=0.8` 에서 참 바닥에너지 아래로 내려감). **바닥상태 트랙은 외부 기준값
없이는 자기 검증이 불가능합니다.** 이것이 §3(2) 의 핵심으로 이어집니다.

## 3. 비스토콰스틱 `Y` 항 — 재심 결과

**결론은 유지: 지금 형태로는 기각.** 그러나 1차(같은 날 오전)에 든 사유 셋
중 **(3)은 철회하고 (2)는 상당히 약화**시킵니다.

### (1) 자기모순 — 유지, 오히려 강화

회로를 만드는 것은 **고전 컴퓨터의 BP-PPS** 입니다. 우리가 훈련할 수 있는
영역은 정의상 **어떤 고전 알고리즘이 성공한 영역**입니다. `Y` 로 QMC 를
죽이는 것은 고전 방법 *하나*를 죽이는 것이지 문제를 고전적으로 어렵게
만드는 것이 아닙니다.

2510.02428 결론부가 직접 씁니다: PPS 의 한계는 부호가 아니라 **magic
(비클리퍼드성)** 이고, 따라서 **"우리 방법은 QMC 가 부호 문제로 어려움을 겪는
모델까지 확장된다"**, 그리고 **"얽힘이 크고 부호 문제가 있으면서 magic 이 낮은
계"** 가 PPS 가 기존 고전 방법을 이기는 영역일 것이라고 **자기 향후 과제로
선언**합니다. 즉 우리가 `Y` 를 넣어 도착하는 곳은 **그들이 미리 깃발을 꽂아 둔
땅**이고, 거기서 나오는 결과물의 이름은 "양자 우위" 가 아니라
**"양자 영감 고전 방법(PPS)이 QMC·DMRG 를 이겼다"** 입니다. 좋은 논문일 수는
있지만 **이 프로젝트가 쓰려는 논문이 아닙니다.**

> **규칙 (`CLAUDE.md` 승격됨).** 고전 훈련으로 회로를 얻는 한 **"고전적으로
> 불가능" 은 어떤 형태로도 주장할 수 없고, 모델을 바꿔서 우회할 수 없습니다.**

### (2) 기준값 상실 — **부분 철회.** 1차 서술이 틀렸습니다

1차에서 "`Y` 를 넣으면 DMRG/PEPS 도 죽어서 기준값이 하나도 없다" 고 썼습니다.
**그 근거는 `new.md` 에서 가져온 것인데, `new.md` 의 논거는 *시간 진화* 에
대한 것입니다** (부피법칙 얽힘 → 본드 차원 폭발). **2D 바닥상태는 면적법칙이라
DMRG(원통형)·PEPS 가 표준적으로 동작합니다.** 실제로 2510.02428 은 정확해가
없는 모형에서 **100+큐비트 2D 바닥상태를 DMRG(ITensor)로 기준값 삼았습니다.**
무질서는 DMRG 에 문제가 되지 않습니다 (병진 대칭을 요구하지 않음).

수정된 표:

| 검증 수단 | `Y` 항 추가 후 (바닥상태 트랙) |
|:--|:--|
| ED | 4×4 에서만 (지금과 동일) |
| QMC | **부호 문제로 사망** — 우리가 일부러 죽인 것 |
| DMRG / PEPS | **살아 있음.** 2D 바닥상태는 면적법칙. 10-폭 원통이 비싸고 임계·무갭에서 나빠지지만 "죽었다" 는 틀린 말 |
| BP-PPS 자신 | 변분 하한이 아니므로 **자기 검증 불가** (§2 마지막 절) |

**남는 힘.** 그래도 (2)가 완전히 사라지지는 않습니다. 첫째, QMC 를 죽이면
**독립적인 기준값이 둘에서 하나로 줄고**, 그 하나(DMRG)는 무갭·임계에서 정확히
우리가 관심 있는 영역과 함께 나빠집니다. 둘째, 우리 손실이 변분 상한이
아니므로 **기준값이 하나뿐인 상태에서 "PPS 에너지가 DMRG 보다 낮다" 는 관측은
승리인지 절단 인공물인지 구분되지 않습니다** — 2510.02428 이 heavy-hex 에서
DMRG 를 이겼다고 보고하면서 바로 그 caveat 을 붙인 것이 이 경우입니다.
**즉 (2)는 "기준값이 없어진다" 가 아니라 "기준값이 하나 남는데 그 하나로는
우리 손실의 편향을 못 걷어낸다" 로 축소됩니다.** 약하지만 여전히 유효합니다.

### (3) 파이프라인 재작업 비용 — **철회.** 사용자 지적이 맞습니다

1차에서 "3항이 되면 타겟 생성·Trotter 경쟁자·게이트 매칭이 전부 재계산" 이라고
썼는데, **그 목록은 시간 진화 트랙의 비용입니다.** 바닥상태 트랙만 놓고 보면:

- **정답 데이터 없음** → 타겟 재생성 0, Trotter 타겟 곡선 0.
- HVA 에 `u_YY(β)` 층 하나 추가 → 엔진은 파울리 곱셈 규칙을 이미 전부
  가지고 있으므로 **생성원 추가는 구조 변경이 아니라 설정 변경에 가깝습니다.**
- **2Q 비용은 결합 배치에 달렸습니다.** 결합마다 `ZZ`/`YY`/`XX` 중 하나를
  주는 **Kitaev 식 본드 분할**이면 층당 2Q 는 **그대로**입니다 (본드당 게이트
  하나). 반대로 모든 본드에 `XYZ` 를 다 걸면 층당 2Q 가 **3배**입니다.
  → **`Y` 를 넣기로 한다면 본드 분할형이어야 합니다.**
- `|+…+⟩` 초기 상태의 근거였던 `Π_i X_i` 패리티가 깨지는 것은 사실이고, 초기
  상태를 다시 정해야 합니다. 이건 실제 비용이지만 재작업 *하나*이지 파이프라인
  전체가 아닙니다.

**따라서 "비싸서 안 된다" 는 더 이상 기각 사유가 아닙니다.** 기각 사유는
(1)과 축소된 (2), 그리고 아래 (4)입니다.

### (4) 새 사유 — `Y` 를 넣는 것 자체가 선행 연구입니다

2510.02428 §5 의 **Kitaev honeycomb** 이 정확히 `-Jx ΣXX - Jy ΣYY - Jz ΣZZ`
이고, 안수는 `U = u_ZZ(α) u_YY(β) u_XX(γ)` 입니다 (Eq. 12–13). 즉
**"HVA 에 `ZZ`, `X`, `Y` 를 넣어 PPS 로 훈련하고 하드웨어에 배포한다" 는 이미
출판되었습니다** — 48큐비트 H2 실행까지 포함해서. 사용자의 "훈련하면 될 것
같은데" 는 **기술적으로 맞습니다. 그래서 새롭지 않습니다.**

남는 차별점은 `Y` 자체가 아니라 **무질서** 하나뿐입니다. 그런데 무질서는
`Y` 없이도 우리가 이미 가지고 있습니다.

## 4. 그래서 사용자의 두 주장을 각각 채점하면

### "compile 우위" — 절반 성립

측정된 사실입니다: BP-PPS HVA `L=3`, **72 2Q** 로 같은 에너지의 단열 1,081 2Q,
VQE 129 2Q (`02` 층위 B). 15.0배 / 1.8배. `Y` 를 넣어도 이 논리는 살아남고,
본드 분할형이면 2Q 통화도 그대로입니다.

**깎이는 곳 셋** (전부 `02` 에 이미 기록):
1. 경쟁자가 SOTA 가 아닙니다. **CD 단열**의 1차 항은 1큐빗이라 우리 통화에서
   공짜이고, **AVQITE** 는 TFIM 에서 CNOT 수가 HVA 의 절반이라고 보고돼
   **우리 안수를 직접 겨냥**합니다.
2. "다중각 HVA 가 단일각을 이긴다" 는 Herrman et al. (2022) 가 이미 보고한
   크기입니다. 새 결과로 팔면 안 됩니다.
3. Lin 2026 이 바닥상태 compile 을 100큐비트에서 이미 했습니다.

→ **compile 축은 "우리가 처음" 이 아니라 "우리가 더 얕다" 입니다.** 그건
   §4 끝의 무질서·역전파 메커니즘 주장에 붙여야 값이 나옵니다.

### "sampling 우위" — 지금 모델에서는 **성립하지 않습니다**

이건 명확히 해야 합니다. **바닥상태 샘플링 우위는 stoquastic 모형에서 원천
봉쇄돼 있습니다** (`02`, `CLAUDE.md`): 진폭이 전부 양수라 QMC 가 `|ψ₀(x)|²`
를 샘플링합니다. 게다가 Nakano et al. 이 얕은 회로 출력 분포를 MADE 로 모방해
스핀글래스 MCMC 에 쓰는 것을 이미 했습니다. **샘플링 우위는 원래부터 시간
진화 쪽 주장**이었고 (진화된 상태는 위상이 `2π` 에 퍼짐), 바닥상태 쪽으로
옮겨 오지 않습니다.

`Y` 를 넣으면? 그때는 진폭에 부호·위상이 생겨 QMC 가 무너지는 것이 맞습니다.
**즉 사용자의 두 주장은 사실 하나입니다 — 바닥상태에서 샘플링 우위를 원하면
비스토콰스틱이 필수입니다.** 그러나 그 길에는 §3 의 (1)(2)(4)가 그대로 있고,
추가로 인증 문제가 붙습니다: **100큐비트에서 분포 주장을 무엇으로 검증하는가.**
에너지는 국소 관측량의 합이라 장치에서 오차막대와 함께 측정되지만, 분포는
아닙니다. 네 조합을 놓고 보면 순위가 분명합니다.

| | 깊이(compile) | 관측량 값 | 분포(samples) |
|:--|:--|:--|:--|
| **바닥상태** | ✅ 측정됨, 인증됨. 단 선행 연구 밀집 | ✅ 인증 가능(QMC/DMRG). 단 고전도 다 됨 | ❌ stoquastic 이면 불가, `Y` 넣어도 인증 불가 |
| **시간 진화** | ⛔ 타겟의 벽 | ⚠️ 인증 간극 없음, 그러나 고전 기준선이 **우리 도구(SPD)** | ⛔ 물리는 여기 있는데 인증 수단이 없음 |

→ **가장 튼튼한 칸은 "바닥상태 × 깊이" 이고, 가장 약한 칸이 "바닥상태 ×
분포" 입니다.** 사용자가 묶은 두 주장 중 앞의 것만 채택합니다.

### 그럼에도 남는 메커니즘 주장 — 무질서 × 해석적 gradient

2510.02428 은 최적화를 감당하려고 **병진 대칭 proxy 해밀토니안**을 씁니다.
균일 모형이라 가능한 일입니다. 무질서는 그 지름길을 원천 봉쇄합니다.

| | 그들 (균일) | 우리 (무질서) |
|:--|:--|:--|
| 파라미터 | 층당 3각 (대칭으로 축약 가능) | 층당 **40각 @4×4, 280각 @10×10** (축약 불가) |
| gradient | **SPSA** (2회 평가/스텝, 확률적 정확도 한계) | **해석적 역전파** |
| 절단 | `1e-3` → `1e-4` | `1e-6` ~ `1e-7` |

> 정정: 이전 판의 "190각 @10×10" 은 오류입니다. 10×10 열린 경계 정사각 격자는
> 사이트 100 + 본드 180 = **층당 280각**입니다.

→ 주장: **무질서 모형에서는 파라미터를 줄일 수 없고, 그 규모에서 SPSA 는
훈련이 안 된다. 해석적 역전파는 편의가 아니라 가능 조건이다.** 측정 가능하고,
아직 아무도 그 곡선을 그리지 않았고, 논문의 저자가 직접 향후 과제로 적었습니다.

**그리고 이 주장은 `Y` 를 넣으면 오히려 강해집니다** — 생성원이 늘수록 각도가
늘고 SPSA 는 더 나빠집니다. 그러니 **비스토콰스틱으로 갈 이유가 있다면 그것은
"QMC 를 죽이려고" 가 아니라 "SPSA 가 확실히 실패하는 파라미터 규모로 가려고"
여야 합니다.** 그쪽 명분은 방어 가능하고, DMRG 기준값도 살아 있습니다.

## 5. 규모에서 무엇을 인증할 수 있나 — 노이즈 예산과 fidelity의 부재

> 2026-09-04, 3차. 사용자 질문: "장치 노이즈가 크면 비스토콰스틱 바닥상태를
> 잴 수 있나? 대규모에서 fidelity 는 어떻게 구하나? 하드웨어를 안 돌리고
> 개념 제안만 하는 건 무리인가?"

### (a) `Y` 는 측정을 어렵게 만들지 않습니다 — 노이즈가 어렵게 만듭니다

**부호 문제는 고전 시뮬레이션의 장애물이지 측정의 장애물이 아닙니다.** 지금
`H` 는 `ZZ`(전부 교환) + `X`(전부 교환) 이라 **측정 세팅 2개**입니다. Kitaev
식 본드 분할이면 `ZZ`/`YY`/`XX` 로 **3개**가 됩니다. 그게 전부입니다.

진짜 장애물은 노이즈입니다. 전역 depolarizing 근사에서
`<H>_측정 ≈ F_circ · <H>_이상` (`H` 는 traceless) 이므로 **상대 에너지 오차가
곧 `1 - F_circ`** 이고, `F_circ ≈ exp(-N_2Q · p)` 입니다.

**10×10 (층당 180 본드), 오차완화 없이:**

| 2Q 오류율 | `L=1` (180g) | `L=2` (360g) | `L=3` (540g) | `L=5` (900g) |
|:--|--:|--:|--:|--:|
| `p=2e-3` (오늘 중앙값) | 30% | 51% | **66%** | 83% |
| `p=1e-3` (낙관) | 16% | 30% | **42%** | 59% |
| `p=3e-4` (미래) | 5% | 10% | **15%** | 24% |

- 상대 오차 **1%** 를 내려면 `L=3` 에서 `p ≈ 1.9e-5` — 오늘보다 **약 100배**
  좋아야 합니다.
- 비교: 2D DMRG 는 보통 **0.1% 이하**. **정면 대결에서 두 자릿수 이상 집니다.**
- 참고로 4×4 `L=3` (72g) 은 `p=2e-3` 에서 노이즈만 13%, 무노이즈 2.1% 와 합쳐
  ~16%. ED 가 있으니 시연은 되지만 주장은 못 됩니다.

### (b) 진짜 딜레마 — 인증과 완화는 양립하지 않습니다

지난 판에서 "100큐비트에서도 장치 측정 에너지는 **인증된 변분 상한**" 이라고
적었습니다. 맞습니다. 그런데:

| | 값의 품질 | 인증 |
|:--|:--|:--|
| **생(raw) 측정** | 위 표대로 40~70% 오차 | ✅ `<H> ≥ E0` 가 엄밀히 성립 |
| **ZNE 등 완화 후** | 경쟁 가능한 수준 | ❌ **외삽이라 상한 보장이 깨짐** — `E0` 아래로 내려갈 수 있음 |

**즉 `Y` 트랙에서 유일하게 살아남던 인증은, 그 숫자를 쓸모 있게 만들려고
완화를 거는 순간 사라집니다.** 이게 §3-(2) 의 최종 형태입니다. "기준값이
없다" 가 아니라 **"인증된 값은 나쁘고, 좋은 값은 인증이 안 된다"** 입니다.

### (c) 대규모에서 fidelity 는 **구할 수 없습니다**

명확히: 100큐비트에서 fidelity 는 **가능한 지표가 아닙니다.** 참 바닥상태의
고전적 기술이 있어야 하는데 없습니다. Direct fidelity estimation 도,
cross-entropy benchmarking 도 회로/상태의 고전 시뮬레이션을 전제합니다.
`02` 의 규모별 표에 10×10 행에 fidelity 가 없는 것이 이 이유입니다.

**대신 쓸 수 있는 것 셋:**

1. **에너지** — 변분 상한. 위 (b)의 딜레마를 안고 감.
2. **국소 관측량** — 자화, 상관함수. 기준값이 있어야 의미가 생김.
3. **에너지 분산** ← **문서에 없던 것. 이게 fidelity 의 자리를 대신합니다.**

`σ² = <H²> - <H>²` 는 **고유상태일 때 정확히 0** 입니다. 그리고 Weinstein 의
부등식으로 **`|E_k - <H>| ≤ σ` 인 고유값 `E_k` 가 반드시 존재**합니다.
`E0` 를 몰라도, 고전 기준값이 하나도 없어도 성립하는 **양측 진술**입니다.
신경망 양자상태(VMC) 문헌에서 분산 외삽으로 표준적으로 쓰는 도구입니다.

- 측정 비용: `H` 가 280항이면 `H²` 는 최대 78,400 곱이지만 교환군으로 묶으면
  **측정 세팅은 O(10)** 입니다. 샷 비용은 크지만 다항식입니다.
- ⚠️ **같은 벽에 걸립니다.** 노이즈는 `σ` 를 위로 밀어올려 bound 를 느슨하게
  만듭니다. 그래도 (b)와 달리 **완화 없이도 방향이 보수적**이라 인증이
  깨지지는 않습니다.
- → **에너지 + 에너지 분산이 100큐비트에서 고전 참값 없이 쓸 수 있는 유일한
  인증 쌍입니다.** `02` 의 "에너지 보존" 항목과 짝지어 `04` 가 예산을 잡아야
  합니다.

### (d) 하드웨어를 안 돌리는 것은 **무리가 아닙니다** — 오히려 지금 데이터에 맞습니다

선례가 확실합니다. **Lin·Pollmann (PRX Quantum 2021)** 은 하드웨어 실행이
없습니다 — MPS 수치 + 회로 제안입니다. **Benedetti et al. (PRResearch 2021)**
은 `n=6` 수치뿐입니다. 둘 다 좋은 저널의 잘 인용되는 논문입니다.

규칙은 하나입니다: **주장이 증거와 맞으면 됩니다.**

| 하드웨어 없이 | |
|:--|:--|
| ❌ 못 쓰는 말 | "양자 유용성", "장치에서 측정했다", "고전을 이겼다" |
| ✅ 쓸 수 있는 말 | "같은 정확도를 `N` 배 적은 2Q 로 얻는다" (자원/컴파일 주장) |
| ✅ 쓸 수 있는 말 | "이 파라미터 규모에서 해석적 gradient 는 가능 조건이다" |
| ✅ 필수 부록 | **노이즈 예산** — 위 (a) 표. 어떤 장치 품질이면 되는지 |

**그리고 이 선택은 (b)의 딜레마를 통째로 없앱니다.** 완화도 인증도 필요 없이,
자원 곡선만 주장하면 되니까요.

**대가는 분명합니다.** `E_QPU < E_DMRG` 라우트가 사라지고, 그러면 장치가
주인공인 논문이 아닙니다. **비스토콰스틱과 "개념 제안만" 은 서로 안 맞습니다** —
하드웨어를 안 돌리면 `Y` 트랙의 결과물은 PPS 가 낸 숫자, 즉 §3-(1) 의
"양자 영감 고전 논문" 이 됩니다. 둘 중 하나를 골라야 합니다.

## 6. 양자 컴퓨터가 바닥상태 *계산*의 주인공이 되려면 (2026-09-04, 사용자 요청)

먼저 지금까지 세 번 돈 고리를 명시합니다.

```
결과물이 "레지스터 안의 상태"  →  고전이 잘 푸는 모델을 골랐으니
                                   QC 가 계산의 주인공이 될 수 없음
   ↓ 모델을 어렵게 만든다 (Y)
QMC 사망  →  인증 수단 축소  →  노이즈 + 완화 딜레마 (§5-b)
   ↓ 하드웨어를 안 돌린다
PPS 가 주인공  →  고전 논문  →  처음으로 되돌아감
```

**나가는 길은 모델을 바꾸는 게 아니라 결과물을 바꾸는 것입니다.** 선택지 셋:

### (1) Warm start + 온디바이스 정제 — QC 가 실제로 일하는 유일한 형태

PPS 로 `θ_0` 를 얻고, **하드웨어에서 거기서부터 VQE 를 이어 돌립니다.**
2510.02428 이 향후 과제로 **직접 지목**했고 (PPS 안에서 warm start 가 크게
도움된다는 관찰까지 하고서) **하지 않았습니다.**

- 측정 가능한 주장: **"PPS warm start 가 하드웨어 최적화 스텝을 몇 배 줄이나."**
- 걸림돌: 층당 280각에서 parameter-shift 는 불가능(스텝당 `2 × 280 × L` 회
  평가). 하드웨어에서는 SPSA + 샷 노이즈 + barren plateau.
- 방어: **warm start 면 최적점 근처라 스텝이 적게 필요하다** — 그게 정확히
  파는 물건입니다. 이 논거가 성립하는지가 실험 내용 자체입니다.

### (2) QC = 해결자가 아니라 **인증자**

PPS 가 회로를 만들고, QC 는 `<H>` 와 `<H²>` 를 재서 **고전이 공짜로 줄 수 없는
인증**(§5-c)을 제공합니다. 주장이 약해지지만 **지금 하드웨어로 가능**하고,
비스토콰스틱이든 아니든 성립합니다.

### (3) 바닥상태를 **목적이 아니라 입력으로** ← 권장

2510.02428 의 마지막 문단이 직접 씁니다: 바닥상태는 고전이 정확히 근사할 수
있어도 **그 동역학 응답과 실시간 동역학은 훨씬 어렵고**, PPS 로 바닥상태를
준비한 뒤 하드웨어로 이후 동역학을 돌리는 것이 **"실용적 양자 우위로 가는
현실적 경로"** 라고.

이 구조에서는 **바닥상태가 고전적으로 쉬운 것이 약점이 아니라 장점**이 됩니다 —
출발점이 인증되니까요. `CLAUDE.md` 가 목표 ③을 "능력 주장" 으로 정의하고
"레지스터 안의 상태는 다음 양자 계산의 입력" 이라고 적어 둔 것이 정확히 이
구조인데, 지금까지 **그 다음 계산이 무엇인지 정한 적이 없습니다.**

- 우리는 **두 조각을 이미 다 갖고 있습니다** — 바닥상태 파이프라인과 시간 진화
  파이프라인. 지금까지 별개 목표로 다뤄서 붙여 본 적이 없을 뿐입니다.
- **§7 의 증분 압축이 정확히 두 번째 조각을 배포 가능하게 만드는 일입니다.**
- 자연스러운 물리량: 바닥상태에서 출발한 **퀜치 후 동역학 응답**, 동적
  감수율, 또는 §8-C 의 OTOC.

> **정리.** "QC 가 바닥상태를 계산했으면" 은 이 모델·이 하드웨어에서 안 됩니다
> (§5-a 의 숫자). **"QC 가 바닥상태에서 출발해 고전이 못 하는 것을 했으면" 은
> 됩니다.** 그리고 그건 우리 두 트랙을 합치는 구조이지 새 프로젝트가 아닙니다.
## 7. 이번 세션의 제안 — 비어 있는 칸은 "시간 진화 × 압축 컴파일"

사용자의 관찰("바닥상태는 타겟이 필요 없다")을 뒤집으면 진짜 질문이 나옵니다:
**시간 진화의 타겟은 정말 필요한가?**

지금 우리는 `T` 까지 **정밀 Trotter(dt=0.001, 500스텝)로 타겟을 통째로 만든
다음** 거기에 회로를 맞춥니다. 그래서 `T>0.5` 에서 항이 폭발하고 stage 1 이
취소됐습니다 (`01` 타겟의 벽). **그런데 2021년 두 논문은 그렇게 하지
않습니다.**

- **Lin·Pollmann (PRX Q 2021)**: 매 스텝 `F = |⟨ψ(t+Δt)|V̂(Δt)|ψ(t)⟩|²` 를
  최대화합니다. 타겟은 **현재 상태에 Trotter 한 스텝**이지 시간 `T` 까지의
  정확해가 아닙니다. 고정 깊이 회로를 매 스텝 재최적화 = **압축**.
- **Benedetti et al. (PRR 2021)**: 같은 구조, 손실은 스텝당 유클리드 거리.

두 논문의 사정을 우리 것과 겹쳐 놓으면 **빈 칸이 하나 보입니다.**

| | 고전 시뮬레이터 | 차원 | 규모 | 무질서 | 대상 |
|:--|:--|:--|:--|:--|:--|
| Lin·Pollmann 2021 | **MPS** | 1D | N=31 | 없음 | 시간 진화 (압축) |
| Benedetti 2021 | **양자 하드웨어**(Hadamard test) | 1D | n=6 | 없음 | 시간 진화 |
| Lin·Gharibyan·Su 2026 | **PPS** | 2D/heavy-hex | 100+ | 없음 | **바닥상태만** |
| **빈 칸** | **PPS** | **2D** | **100** | **있음** | **시간 진화 (압축)** |

그리고 **왜 아무도 안 했는지**에 대한 기술적 이유가 우리에게 유리합니다.
Lin·Pollmann 과 Benedetti 의 손실은 **전역 겹침(fidelity)** 입니다. 전역
겹침은 `|0⟩⟨0|^{⊗N} = Π_i (I+Z_i)/2` 라 파울리 항이 `2^N` 개 —
**파울리 전파로는 계산할 수 없습니다.** 그래서 그들은 MPS 를 쓰거나
하드웨어에서 Hadamard test 를 돌립니다. 우리의 `L_XZ` 는 **국소 생성원
`{X_i, Z_i}` 위의 연산자 거리**라 항 수가 `2N` 이고, **파울리 전파와 애초에
호환되는 손실입니다.** 이건 우연이 아니라 우리 설정의 실질적 기술 자산인데
지금까지 아무 문서에도 그렇게 적혀 있지 않습니다.

### 구체적 제안: 증분 압축 (incremental compilation)

고정 깊이 `L` 회로 `U(θ)` 를 유지하면서, 스텝 `n → n+1` 에서

```
목표:  U(θ_{n+1})  ≈  V̂(Δt) · U(θ_n)          (V̂ = Trotter 한 스텝)
손실:  L_XZ(θ_{n+1})  with  target_G  =  U(θ_n)† V̂(Δt)† G V̂(Δt) U(θ_n),
                                          G ∈ {X_i, Z_i}
```

타겟은 **우리 엔진이 이미 하는 일 그대로** 만듭니다 — `G` 를 Trotter 한
스텝(항이 거의 안 늘어남) 통과시킨 뒤 **훈련된 고정 깊이 회로 `U(θ_n)`**
을 통과시킵니다. 즉 **타겟 생성 비용이 gradient 평가 한 번과 같은 규모**이고,
`T` 에 따라 폭발하지 않습니다. `dt=0.001` 짜리 500스텝 정밀 전파가 사라집니다.

**대신 무엇을 내주는가 (정직하게).** 타겟이 이제 *정확해*가 아니라 *이전
스텝의 회로*에서 나오므로 **오차가 스텝마다 누적**됩니다. p-VQD 계열의 알려진
약점입니다. 그러나 이건 **"타겟을 아예 못 만든다" 를 "타겟 오차가 누적된다"
로 바꾸는 것**이고, 후자는 측정하고 통제할 수 있는 문제입니다 (스텝 크기,
깊이, 절단 임계값으로). 지금은 전자라 stage 1 이 취소돼 있습니다.

**이게 서면 무엇이 달라지나.**
- `T>0.5` 가 열립니다 → `01` 의 타겟의 벽 해제, 스케일링 우위 주장 가능.
- `t*` 를 실제로 측정할 수 있는 회로가 생깁니다 (`02` 의 전제).
- 그리고 **방법론 기여가 생깁니다** — `new.md` 의 핵심 불만("방법은 새로울 게
  없다")에 대한 유일한 실질적 답입니다. 파울리 전파로 압축 컴파일을 돌리려면
  손실을 국소 연산자 거리로 바꿔야 한다는 것이 그 기여의 내용입니다.

**착수 전에 재야 할 것 (아직 안 했습니다).**
1. `U(θ_n)` 통과 후 타겟 항 수가 실제로 얼마인가. 훈련 regime(≈400K 항)과
   같은 자릿수여야 합니다. → 4×4 에서 스텝 5개만 돌려 보면 압니다.
2. 오차 누적률. 4×4 는 ED 가 있으므로 `T=0.5, 1.0, 1.5, 2.0` 에서 곧바로
   채점됩니다.
3. 고정 깊이 `L` 을 얼마로 두어야 `T` 가 커져도 버티는가 — 못 버티면 깊이가
   `T` 에 선형이 되고, 그건 지금의 `U(θ;0.5)^k` 합성과 같아져 새로울 것이
   없습니다. **이 3번이 제안의 성패입니다.**

> 구현 전이라 `RUNBOOK.md` 에 넣을 명령이 아직 없습니다. 스크립트가 생기면
> 1·2번을 4×4 실험 하나로 묶어 실행 대기열에 올립니다.

## 8. 방향 정리 — 우선순위 순

### A. 무질서를 축으로, 해석적 gradient 를 가능 조건으로 (바닥상태) ← 즉시 가능

QMC 기준값이 살아 있고, 이건 숨길 약점이 아니라 내세울 강점입니다.

### B. 증분 압축 (시간 진화) ← 잠재적 최대 수익, 미검증

§7. 성공하면 방법론 기여 + 타겟의 벽 해제. 실패해도 4×4 에서 싸게 판정납니다.
**A 와 B 는 경쟁하지 않습니다** — A 는 이미 있는 데이터로 그림을 그리는 일이고
B 는 새 코드입니다.

### C. "상태" 에서 "관측량" 으로

"상태를 준비했다" 보다 "물리량을 측정했다" 가 논문으로서 위입니다. `Y` 항과

노이즈 예산 밖입니다 → T3 안건, `04` 에서 예산부터.

### D. 비스토콰스틱 — 보류. 가려면 명분을 바꿔서

`Y` 자체는 기각이 아니라 **보류**이고, 간다면 명분은 **"SPSA 가 실패하는
파라미터 규모"** 이지 "QMC 살해" 가 아닙니다 (§4). 착수 전 조건 넷:

1. **이름 있는 모형.** 급조한 `Y` 항이 아니라 문헌에 있는 것. 가장 자연스러운
   후보는 **무질서 Kitaev honeycomb** — Lin 2026 이 균일판을 했으므로
   "거기에 무질서를 넣었다" 가 명분이 되고, **본드 분할형이라 층당 2Q 가 늘지
   않습니다** (§3-(3)). ⚠️ 단, 그러면 우리 모형이 EA 스핀글래스가 아니게
   되므로 프로젝트 정체성이 바뀝니다. 사용자 결정 사항입니다.
2. **검증 수단을 먼저.** DMRG 가 살아 있다는 것이 §3-(2)의 정정이지만,

   에너지 스케일링 곡선(2510.02428 의 권고)을 검증 절차로 못박을 것.
3. **BP-PPS 가 거기서 수렴하는지 먼저 확인.** 한계는 부호가 아니라 magic.
4. **초기 상태 재설계.** `Π_i X_i` 패리티가 깨집니다.

모델을 옮깁니다.**

### 왜 "고전적으로 불가능" 을 못 쓰는가 — 두 줄 설명

> 자주 다시 나오는 질문입니다 (2026-09-04 사용자). "바닥상태 훈련은 정답
> 데이터가 필요 없으니, 손실함수만 정해서 회로를 만들면 '고전적으로 불가능'
> 을 주장할 수 있는 것 아닌가?"

**아닙니다. 이유는 모델이 아니라 파이프라인에 있습니다.**

θ 를 최적화하려면 BP-PPS 가 `E(θ) = ⟨+|U(θ)† H U(θ)|+⟩` 를 **고전 CPU 에서
수천 번 계산**해야 합니다. 그게 되면 BP-PPS 는 이미 **시험 상태의 에너지를
계산하는 고전 알고리즘**이고, θ 에 대한 최소화까지 고전에서 끝납니다. 훈련이
끝난 시점에 고전 컴퓨터는 **에너지와 상태의 완전한 기술을 둘 다 손에 쥐고
있습니다.** 양자 컴퓨터는 아직 등장하지도 않았습니다.

"정답 데이터가 없다" 는 **손실이 자기충족적이라는 뜻이지 손실 계산이 쉽다는
뜻이 아닙니다.** 어려움이 "정답지 생성" 에서 "시험 상태의 `⟨H⟩` 평가" 로
옮겨갔을 뿐이고, BP-PPS 가 하는 일이 정확히 그 평가입니다.

**그리고 근본 원인은 얕음입니다** (사용자 추측이 맞습니다):

```
고전이 못 묘사할 만큼 깊다  →  노이즈로 장치에서도 못 돌리고,
                               BP-PPS 도 훈련을 못 함
장치에서 돌아갈 만큼 얕다   →  훈련한 그 방법으로 고전이 묘사됨
```

**하드웨어에 올리려고 요구하는 얕음과, 고전 시뮬레이션을 가능하게 하는 얕음이
같은 조건입니다.** 모델을 바꿔서 빠져나갈 수 없는 이유가 이것입니다.

두 가지 단서는 달아 둡니다. (a) PPS 가 주는 것은 **기댓값**이지 샘플이 아닙니다 —
얕은 2D 회로에서 **샘플링**은 여전히 고전적으로 어렵다고 믿어집니다. 다만 이
계획의 주장은 에너지와 상태 준비이고, 에너지는 정확히 PPS 가 주는 것이라
이 계획에는 도움이 안 됩니다. (b) 유일한 탈출구는 **PPS 가 못 가는 곳까지
하드웨어가 최적화를 이어가는 것**(warm start + 온디바이스 정제, §6-1)이고,
그건 QPU 에서 최적화를 돌린다는 뜻이라 이 계획의 범위 밖입니다.

**그래서 정확한 주장은 "고전적으로 불가능" 이 아니라 "QMC 가 실패한다" 입니다.**
QMC 실패 ≠ 모든 고전 방법 실패 — 우리 BP-PPS 자신이 실패하지 않는 고전
방법입니다. 이건 약점이 아니라 정확한 문장이고, 아래 셋은 전부 참입니다.

1. **QMC 는 이 모델에서 실패한다** (부호 문제를 실측해서 보임)
2. **HVA + BP-PPS 는 같은 정확도를 훨씬 얕은 회로로 얻는다** (경쟁자 대비 2Q)

`Y` 를 본드에 넣어야 부호 문제가 생깁니다. 사이트 항(`h_y Y_i`)은 안 됩니다 —
사이트별 `Z` 회전으로 `X` 로 되돌아가는 게이지 변환이 존재해서 **stoquastic
으로 되돌릴 수 있습니다.** 리뷰어가 한 줄로 죽입니다.

### A 에 부호 문제와 frustration 이 둘 다 있나 — 예, 둘 다 있고 서로 다른 것입니다

`CLAUDE.md` 의 "frustration ≠ 부호 문제" 를 지켜서 따로 씁니다.

- **frustration: 두 겹으로 있습니다.** (i) `ZZ` 본드의 무작위 부호에서 오는
  지금과 같은 고전적 frustration, (ii) **compass 구조 자체의 frustration** —
  본드마다 다른 스핀 성분을 정렬시키려 해서 동시에 만족시킬 수 없습니다.
  무질서가 없어도 (ii)는 남습니다.
- **부호 문제: 있을 것으로 예상되지만 반드시 확인해야 합니다.** `-J·YY` 는
  `|00⟩↔|11⟩` 자리에 양의 비대각을 만들어 계산 기저에서 비스토콰스틱입니다.
  ⚠️ **그런데 stoquastic 여부는 기저 의존적입니다.** 사이트별 `Z` 축 π 회전은
  `XX`·`YY` 본드의 부호를 뒤집고 `ZZ` 는 그대로 둡니다. 그래서 부호를 게이지로
  없앨 수 있느냐는 **모든 플라케트의 Z2 플럭스가 자명하냐** 는 문제가 됩니다.
  무작위 부호면 일반적으로 좌절되어 못 없앱니다 — **하지만 이건 논증이지
  측정이 아닙니다.**

  → 단계 0 에서 기존 stoquasticity 체커를 A 에 돌리고(계산 기저, 값쌉니다),
  **진짜 증거는 단계 2 의 평균 부호 붕괴 곡선**입니다. 게이지 논증에 기대지
  말고 측정으로 보이세요.

### 4단계 — 규모 확장과 검증 도구

- 7×7 → 10×10. 비트패킹 필수, **정렬키 32큐비트 한계 때문에 키 폭 확장 선행** (`03`)
- 기준값: 현행 모델이면 QMC + DMRG, 모델 A 면 DMRG 하나
- **기준값 없는 자체 인증: 에너지 + 에너지 분산.** `σ² = <H²> - <H>²` 가 0 이면
  고유상태이고, Weinstein 부등식으로 `|E_k - <H>| ≤ σ` 인 고유값이 존재합니다.
  `E0` 를 몰라도 성립 (§5-c). `<H²>` 추정기 구현 필요
- 크기마다 절단 스케일링 곡선 — PPS 에너지를 믿어도 되는지의 유일한 근거
- 💡 **경쟁자들도 같은 PPS 추정기로 재면 절단 편향이 상당 부분 상쇄됩니다.**
  100큐비트에서 깊이 비교를 유지하는 방법입니다

### 5단계 — 하드웨어 (선택, 나중)

노이즈 예산(§5-a)상 10×10 `L=3` 생측정은 40~70% 오차라 **주장이 아니라
시연**입니다. 현실적 형태는 4×4~5×5 존재 시연이고 규모 주장은 고전으로
유지합니다. 1~4 단계를 막지 않습니다. 예산은 `04` 가 소유합니다.
