# 06 — 독창성과 논문 포지셔닝

담당 범위: **"이 연구의 새로운 점이 무엇인가"** 한 가지. 선행 연구가 무엇을
가져갔는지, 남은 것이 무엇인지, 방향을 어떻게 고칠지를 여기서 정합니다.
숫자는 `../status_4x4.md`, 비교 대상의 범위는 `02-comparison-models.md`.

> 시작: 2026-09-04. `docs/new.md` 의 문제 제기와 `documents/` 에 새로 들어온

## 1. 진단 — `new.md` 의 자기 평가는 맞습니다

> "Time evolution 은 BP-PPS 방식과 똑같고 모델만 바꾼 것, GS preparation 은
> ma-QAOA 에 BP-PPS 를 결합한 것"

**동의합니다.** 새 논문들을 읽고 나면 더 나빠집니다. 아래가 각 논문이
가져가는 부분입니다.

| 선행 연구 | 무엇을 가져가나 |
|:--|:--|
| **Lin·Gharibyan·Su**, *Quantum* 10, 2014 (2026), arXiv:2510.02428 | **목표 ③ 전체.** 파울리 경로로 고전 훈련 → 100+큐비트 바닥상태 → Quantinuum H2 48큐비트 실행, 상대 에너지 오차 5%. 2D 정사각·heavy-hex Ising, Kitaev honeycomb. |
| **Lin·Dilip·Green·Smith·Pollmann**, *PRX Quantum* **2**, 010342 (2021) | **목표 ① 의 착상.** 제목이 그대로 "Real- and Imaginary-Time Evolution with **Compressed Quantum Circuits**". 고전에서 게이트를 최적화해 압축하고 QPU 에 올립니다. |
| **Benedetti·Fiorentini·Lubasch**, *PRResearch* **3**, 033083 (2021) | 시간 진화용 하드웨어 효율 변분 알고리즘. 우리 "블록 하나 훈련 후 반복" 은 이 계열입니다. |
| **Nakano·Okada·Fujii**, *PRX Quantum* **7**, 010338 (2026) | **목표 ② 에 대한 압박.** 얕은 QAOA 회로의 출력 분포를 MADE(고전 신경 샘플러)로 **모방**해 MCMC 제안 분포로 씁니다. 스핀글래스 대상. |
| QGen, ICLR 2026 (스크램블링·붕괴 생성모형) | 주변부. 양자 생성모형 프레이밍 참고용. |

**"고전 훈련 + 얕은 회로 배포" 는 2021년에 제안됐고 2026년에 100큐비트에서
완결됐습니다.** 이 축에는 남은 공간이 없습니다.

### 아프지만 유용한 한 줄

2510.02428 의 결론부는 향후 과제로 **"automatic differentiation 을 도입하면
비용 함수 평가 횟수를 줄일 수 있다"** 고 적습니다. 우리의 BP-PPS 해석적
역전파가 **그들이 필요하다고 적어 둔 바로 그것**입니다. 발명은 아니지만,
"필요하다고 지목된 것을 실제로 해냈다" 는 위치는 인용 가능한 기여입니다.

## 2. `new.md` 의 처방(비스토콰스틱 `Y` 항 추가)은 기각합니다

제안: 스핀글래스에 `Y` 방향 상호작용을 넣어 부호 문제를 만들고, QMC 가 무너진
영역을 하드웨어로 뚫는다.

**진단은 옳지만 처방은 성립하지 않습니다.** 독립적인 이유가 셋입니다.

### (1) 자기모순 — 우리 훈련기 자체가 고전 시뮬레이터입니다

회로를 만드는 것은 **고전 컴퓨터의 BP-PPS** 입니다. 우리가 훈련할 수 있는
영역은 정의상 **어떤 고전 알고리즘이 성공한 영역**입니다. QMC 를 죽이는 것은
고전 방법 *하나*를 죽이는 것이지 문제를 고전적으로 어렵게 만드는 것이
아닙니다.

게다가 2510.02428 이 직접 씁니다: 파울리 경로 방법의 한계는 부호가 아니라
**magic(비클리퍼드성)** 이며, 그래서 **"우리 방법은 QMC 가 부호 문제로
어려움을 겪는 모델까지 확장된다"** 고 자기 영역으로 선언합니다. 즉 부호 문제는
PPS 가 **살아남는** 축입니다. `Y` 를 넣어 QMC 를 죽이면 우리 훈련기는 그대로
살아서, "고전이 못 하는 것을 양자가 했다" 가 아니라 "고전(PPS)이 만든 회로를
양자에서 돌렸다" 가 됩니다. 그건 지금과 같은 문장입니다.

> **규칙으로 승격.** 고전 훈련으로 회로를 얻는 한, **"고전적으로 불가능" 은
> 어떤 형태로도 주장할 수 없습니다.** 이미 `CLAUDE.md` 와 `02` 가 목표 ③에
> 대해 금지하던 것을, 모델을 바꿔서 우회할 수 없다는 뜻입니다.

### (2) 우리 자신의 기준값을 없앱니다 — 이게 더 치명적입니다

`02` 가 정한 구조: **QMC 는 경쟁자가 아니라 기준값 제공자**입니다. ED 가 없는
100큐비트에서 장치를 검증할 유일한 수단입니다.

그리고 2510.02428 이 남긴 경고가 정확히 여기에 꽂힙니다 — 절단된 PPS 의 변분
에너지는 **참 바닥에너지보다 아래로 내려갈 수 있고**, "신뢰할 다른 고전
기준선이 없을 때 이것이 문제가 된다" 고 명시합니다.

`Y` 항을 넣으면 이렇게 됩니다.

| 검증 수단 | `Y` 항 추가 후 |
|:--|:--|
| ED | 4×4 에서만. 100큐비트에는 없음 (지금과 동일) |
| QMC | **부호 문제로 사망** — 우리가 일부러 죽인 것 |
| DMRG / PEPS | 2D + 부피법칙 얽힘으로 사실상 사망 (`new.md` 의 논거 그대로) |
| BP-PPS 자신 | 변분 하한이 아니므로 **자기 검증 불가** |

남는 것은 **믿을 수 없는 고전 훈련기 + 검증 불가능한 장치 + 참값 없음**
입니다. 이건 양자 유용성 논문이 아니라 확인할 수 없는 주장입니다. 심사자가
첫 번째로 묻습니다: "이 에너지가 맞는지 어떻게 압니까?"

### (3) 비용 — 파이프라인의 대부분을 다시 만들어야 합니다

`H` 가 2항(`X`, `ZZ`)에서 3항이 되면 아래가 전부 움직입니다.

- HVA 한 층에 세 번째 생성원이 붙습니다 → 층당 각도·깊이·2Q 비용 재정의,
  4색 병렬 배치 재설계
- 타겟 생성(정밀 Trotter), Trotter 경쟁자 곡선, 게이트 매칭 기준 전부 재계산
- `|+…+⟩` 초기 상태의 근거였던 `Π_i X_i` 패리티가 **더 이상 보존되지
  않습니다** (`CLAUDE.md` 의 근거가 무효)
- `00_validate_small.py` 의 22개 테스트 상당수와 light cone 분석

**그리고 물리적 명분이 약합니다.** "QMC 를 깨려고 설계한 해밀토니안" 은
강점이 아니라 심사에서 약점입니다. 표준 모형이 아니면 "왜 이 모델인가" 에
답이 없습니다.

## 3. 그런데 `new.md` 가 맞힌 것 — 부호 문제는 이미 우리에게 있습니다

**`Y` 항 없이도 QMC 는 죽습니다. 실시간 진화에서요.** `02` 가 이미 적어 둔
그대로입니다: 바닥상태는 진폭이 전부 양수라 QMC 가 샘플링하지만,
`exp(-iHt)` 는 `i` 때문에 진폭이 복소가 되고 QMC 가 무너집니다. 텐서
네트워크는 얽힘 부피법칙으로 무너집니다.

즉 **모델을 바꿔서 얻으려던 것을 목표 ①·②가 이미 가지고 있습니다.**
해밀토니안은 stoquastic 으로 두고 — 그래서 **바닥상태 쪽에서는 QMC 기준값을
유지하고** — 어려움은 동역학에서 취하는 것이 옳은 구조입니다.

막는 것은 프레이밍이 아니라 **숫자**입니다: `t*` 미측정, 그리고 10×10 `t`=2,
`ε`=3e-3 에서 `F`=0.013. 이건 `01`·`04` 의 문제입니다.

## 4. 방향 수정안 — 세 갈래, 우선순위 순

### A. **무질서를 축으로, 해석적 gradient 를 가능 조건으로** ← 권장

2510.02428 의 본문에 결정적인 대목이 있습니다: 그들은 최적화를 감당하려고
**병진 대칭을 이용한 proxy 해밀토니안**을 씁니다. 균일 모형이라 가능한
일입니다. 무질서는 그 지름길을 원천 봉쇄합니다.

| | 그들 (균일) | 우리 (무질서) |
|:--|:--|:--|
| 파라미터 | 층당 3각 (대칭으로 축약 가능) | 층당 40각 @4×4, 190각 @10×10 (축약 불가) |
| gradient | **SPSA** 추정 | **해석적 역전파** |
| 최적화 보조 | 병진 대칭 proxy `H` | 없음 |

→ 주장은 이렇게 됩니다. **무질서 모형에서는 파라미터를 줄일 수 없고, 그러면
SPSA 로는 훈련이 안 된다. 해석적 역전파는 편의가 아니라 가능 조건이다.**
이건 측정 가능한 정량 주장이고, **아직 아무도 그 곡선을 그리지 않았습니다.**

- 대표 그림: **무질서 세기 vs 우위 배수**, 무질서 0 에서 우위도 0 으로 수렴.
  실험은 이미 대기열에 있습니다 — `../RUNBOOK.md` §2-3.
- 4×4 의 15.0배(단열) / 1.8배(VQE)가 일화가 아니라 **메커니즘**이 됩니다.
- **stoquastic 을 유지하므로 QMC 기준값이 살아 있습니다.** 100큐비트에서
  장치를 검증할 수 있다는 것은 숨길 약점이 아니라 **내세울 강점**입니다.
- 추가 실험: 같은 회로·같은 각도 개수에서 **SPSA vs BP-PPS 수렴 비교**.
  2510.02428 이 향후 과제로 적은 것을 우리가 측정으로 답하는 그림입니다.

### B. 실시간 동역학 — 부호 문제를 공짜로 얻는 자리

3절 그대로. 모델을 건드리지 않고 **긴 시간**에서 어려움을 취합니다.
착수 조건은 프레이밍이 아니라 `t*` 측정과 노이즈 예산입니다.

### C. "상태" 에서 "관측량" 으로 — `new.md` 가 옳게 짚은 부분

"상태를 준비했다" 보다 "물리량을 측정했다" 가 논문으로서 위입니다. OTOC·
스크램블링, 또는 무질서 평균 감수율. **이 방향 수정은 `Y` 항과 무관하게
유효하며 채택합니다.** 다만 OTOC 는 정·역 진화 각 2회로 **깊이가 4배**라
지금의 노이즈 예산 밖입니다 → T3 안건, `04` 에서 예산부터.

## 5. 그래도 비스토콰스틱으로 가겠다면 — 최소 조건

기각은 "이 형태로는 안 된다" 이지 "영원히 안 된다" 가 아닙니다. 착수 전에
넷이 필요합니다.

1. **이름 있는 모형을 고를 것.** 급조한 `Y` 항이 아니라 문헌에 있는 모형
   (무작위 이방성 XYZ, 무질서 Kitaev 등). "왜 이 해밀토니안인가" 에 답이 필요.
2. **검증 수단을 먼저 정할 것.** 100큐비트에서 ED·QMC 없이 무엇으로
   확인하는가. 답이 없으면 시작하지 말 것 — 2절 (2).
3. **BP-PPS 가 거기서 수렴하는지 먼저 확인할 것.** 우리 한계는 부호가 아니라
   magic 입니다. 절단 임계값 대비 에너지 스케일링 곡선(2510.02428 의 권고)을
   그려 보고 판단.
4. **파이프라인 재작업 비용을 계상할 것** — 2절 (3) 목록.

## 6. 새 한 문장 (제안)

기존 (`05-writing.md`, 09-03):

> 무질서 해밀토니안에서, 본드별 자유도를 가진 얕은 회로를 고전에서 훈련하면,
> 스케줄 기반 경로보다 같은 정확도를 훨씬 적은 2Q 게이트로 얻는다.

**이 문장은 여전히 맞습니다.** 바꿀 것은 문장이 아니라 **기여의 위치**입니다.

> 기여는 알고리즘이 아니라 **"무질서가 고전 훈련-양자 배포 방식의 실제
> 병목이며, 파라미터를 줄일 수 없는 그 영역에서는 해석적 gradient 가
> 가능 조건이다"** 라는 측정된 사실이다.

세 줄로 정리한 기여 목록:

1. **무질서 2D 모형에서의 첫 PPS 훈련-배포.** 선행 연구는 전부 균일 모형.
2. **SPSA 가 실패하는 파라미터 규모에서의 해석적 gradient** — 선행 연구가
   향후 과제로 지목한 것을, 필요성의 측정과 함께.
3. **utility 규모에서 QMC 를 기준값으로 쓰는 검증 구조.** stoquastic 을
   유지한 것의 대가가 아니라 이득.

**목표 등급은 정직하게.** 이 구성은 `PRX Quantum` 급의 탄탄한 논문이지
Nature 급 "양자 우위" 논문이 아닙니다. Nature 급을 노리려면 2절 (2)의 검증
문제를 푸는 새로운 아이디어가 필요하고, 지금은 없습니다.
