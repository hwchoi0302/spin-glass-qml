# 05 — 문서와 주장 문구

담당 범위: `documents/spin-glass-qml-report.md`, `documents/report.tex`, 그리고
"우리가 정확히 무엇을 주장하는가"의 문장 관리.

## 핵심 논지 한 문장

BP-PPS로 고전 훈련한 얕은 파라미터 회로가, 같은 정확도에서 Trotter보다 얕고,
고전 SPD가 무너지기 시작하는 시간 구간에서도 하드웨어 예산 안에 들어가는
**창(window)** 이 존재한다.

## 이미 고친 것 — 되돌리지 말 것

**부호 문제 서술을 제거했습니다.** 이 해밀토니안은 어떤 `J` 에 대해서도
stoquastic 이라 부호 문제가 없습니다. frustration 은 있지만 그것과 부호 문제는
다른 것입니다. 자세한 근거는 `02-comparison-models.md`.

바닥상태 준비를 **"고전적으로 불가능"이 아니라 "회로 깊이 우위"** 로 재구성
했습니다. QMC가 이 모델의 바닥상태를 샘플링할 수 있으므로 그쪽으로는 주장이
서지 않습니다.

### `Δt` 라벨이 실제 스텝 크기가 아니었습니다

`TrotterCircuit.num_steps` 는 `⌈t/Δt⌉` 로 올림한 뒤 스텝을 `t/steps` 로 줄여
`t` 에 정확히 착지합니다. **`Δt` 는 상한이지 약수가 아닙니다.** `t=0.5` 의
"`Δt=0.2`" 는 실제로 **1/6 짜리 3스텝**이고, `t=0.1` 에서는 `Δt=0.1` 과 아예
같은 회로입니다 (그래서 두 곡선이 거기서 겹쳤습니다).

게이트 수가 `3 × 24 = 72` 로 HVA 3층과 동수라 **비교 자체는 공정했고 `×2.3` 은
유효**합니다. 틀린 건 숫자가 아니라 라벨이었습니다. 그림·문서 모두 `Δt ≤ x` 로
바꾸고 실제 스텝 수를 병기했습니다. **논문에서도 `Δt = 0.2` 라고 쓰지 마세요.**

### `report_goal3_layers.png` — `L=5` 를 넣었습니다

바닥상태 ceiling 은 **철회 대상이 아닙니다.** `a45a88a` 가 죽인 것은 시간진화

**같은 안수가 낼 수 있는 최선**이 맞습니다.

| `L` | ceiling 격차 | 실제 BP-PPS 격차 | |
|--:|--:|--:|:--|

`L=5` 점을 넣은 이유: 넣지 않으면 "BP-PPS 가 ceiling 에 도달한다" 가 **모든

다만 그 `L=5` 실행은 41시간 만에 L-BFGS-B 안에서 죽어 Adam 만 끝난 상태라
**"도달 못 한다" 의 증거가 아니라 미완 최적화의 하한**입니다 — 그림에도 그렇게
적어 뒀습니다. 패널 (b) 에는 `L=5` 마커가 없습니다. fidelity 는 상태가 있어야
하는데 각도가 사라졌기 때문입니다.

### `report_goal2_hardness.png` — 반집중은 **학습된 것이 아닙니다**

이게 이 그림에서 가장 오해받기 쉬운 지점이라 문서에 못박습니다.

훈련 목적함수는 `L_XZ` — 단일 사이트 `X`/`Z` 기댓값을 `exp(-iHt)` 의 것과
맞추는 것뿐입니다. **반집중이나 얽힘에 대한 훈련 압력은 어디에도 없습니다.**
(a)(b) 가 보여 주는 것은 회로가 근사하는 **물리적 시간진화 상태 자체**의
성질입니다. 해밀토니안의 실제 동역학이 곱상태를 스크램블하는 것이고, 회로는
그걸 따라가고 있을 뿐입니다.

그 증거가 그림 안에 있습니다: **`L=2` 와 `L=3` 곡선이 (a)(b) 에서 거의
겹칩니다.** 안수 깊이를 1.5배로 늘려도 반집중·얽힘이 변하지 않는다는 것은,
그것이 안수의 성질이 아니라 타겟 상태의 성질이라는 뜻입니다. 그리고 이것이
`L=2` 를 쓰는 근거입니다 — 같은 "어려움" 을 게이트 2/3 로 삽니다.

- **(a) 반집중**: `Z = 2^n Σ_x p(x)²`. `Z=2` 가 Porter–Thomas (Haar). `k=1` 은
  `Z=139.5` 로 극도로 뾰족해 목표 2에 못 씁니다. `k≥4` 에서 `Z≈2.6` 으로
  Porter–Thomas 에 근접합니다.
- **(b) 얽힘**: 절반 절단 엔트로피가 Haar 값 7.28비트(최대 8비트)로 포화.
  `k≈6` 이후 평평합니다.
- **(c)** 는 **10×10 투영**입니다 — 4×4 에서 잰 알고리즘 fidelity 를 그대로
  쓰고, 거기에 하드웨어 항 `exp(-n_2Q · ε)`, `ε=1e-3`, `n_2Q = 180·L·k` 를
  곱합니다. 결론은 **하드웨어 지수항이 알고리즘 차이를 압도하므로 `L=2` 가
  총합에서 이긴다**는 것.
  ⚠️ **알고리즘 fidelity 를 4×4 에서 10×10 으로 그대로 옮긴 것은 측정이 아니라
  외삽입니다.** 논문에 쓸 때 반드시 그렇게 표기해야 합니다.

### `report_noise_budget.png` — 제목이 관측량 이야기를 샘플링 이야기로 읽히게 했습니다

세 패널:

- **(a)** 단일 사이트 관측량의 역방향 광원뿔 안에 든 2Q 게이트 비율. 10×10,
  `L=2` 에서 `t=0.5` 면 회로의 **27%** 만 그 관측량에 닿을 수 있고, `t=4` 면
  90%. 4×4 는 `t=0.5` 에 이미 82% 라 **작은 격자에서는 광원뿔이 절약이 안
  됩니다.**
- **(b)** 그 절약분. `F_global = exp(-n_total·ε)` 대 `F_local = exp(-n_cone·ε)`.
  10×10 `L=2` 에서 약 2.4배.
- **(c)** 선형 XEB 로 `F` 를 10% 정밀도로 **추정**하는 데 필요한 샷 수,
  `M = 100/F²`.

**"샷을 많이 쏘면 정확한 샘플링을 얻을 수 있나?" — 아닙니다.** 제목이 그렇게
읽히게 돼 있었고 (`averaging recovers the signal cheaply`), 고쳤습니다.

- **관측량이면 됩니다.** 탈분극 노이즈는 `<O>` 를 대략 `F` 배 합니다. `F` 를
  알면 되돌릴 수 있고 대가는 분산뿐이라 `1/F²` 샷입니다. 이게 (c) 가 세는
  것이고 실제로 쓰는 기법입니다. **목표 1이 여기 삽니다** — 10×10 에서
  `t≈2` 까지 `ε=3e-3` 이면 5.6e5 샷으로 예산 안입니다.
- **샘플링이면 안 됩니다.** 확률분포에는 되돌릴 스케일 인자가 없습니다.
  10×10 `L=2` `t=2`, `ε=3e-3` 이면 `F=0.013` — **비트스트링의 약 99%가
  노이즈에서 나옵니다.** 샷을 아무리 늘려도 그 99%는 그대로입니다.
  **목표 2가 샘플링 주장**이므로, (c) 는 목표 2가 `t=2` 까지 산다는 뜻이
  **아닙니다.** `t=2` 에서 fidelity 를 *잴 수 있다*는 뜻입니다.

게다가 `exp(-n·ε)` 모델 자체가 낙관적입니다. 2Q 탈분극만 세고 **판독 오차,
crosstalk, coherent 누적을 전부 뺐습니다.** 100큐비트에서 큐비트당 판독 오차
1e-2 만 넣어도 게이트를 하나도 돌리기 전에 `0.99¹⁰⁰ ≈ 0.37` 입니다.
