# 이슈별 작업 파일

한 세션에서 모든 주제를 다루면 문맥이 뒤섞이고, 압축이 일어날 때마다 이미
정한 것을 다시 논의하게 됩니다. 그래서 주제를 파일로 갈라 두고, **세션 하나가
파일 하나를 담당**합니다.

## 쓰는 법

1. 작업할 주제의 파일을 고릅니다.
2. 그 주제 전용 세션을 새로 엽니다 (프로젝트 폴더에서 `claude` 를 새로 실행).
   `CLAUDE.md` 는 자동으로 읽히므로 프로젝트 배경은 설명할 필요가 없습니다.
3. 첫 메시지로 담당 파일만 지정합니다. 예:
   > `docs/issues/03-engine-performance.md` 를 읽고, 7×7 비트패킹 엔진을 설계해줘.
4. 세션을 끝낼 때 **그 파일의 "상태 / 결정 / 열린 질문"을 갱신**하고 커밋합니다.
   이게 다음 세션의 시작점이 됩니다.

이어서 하려면 `claude --resume` 으로 예전 세션 목록에서 고르면 됩니다.
노트북과 데스크탑에서 문맥을 공유하는 수단은 세션이 아니라 **이 파일들과 git**
입니다. 세션 기록은 기계 밖으로 나가지 않습니다.

## 갈래를 나눌 때의 기준

- **여러 파일에 걸치는 결정**은 `CLAUDE.md` 에 한 줄로 올립니다 (예: 게이트 순서
  규약, 비트패킹 전환 시점).
- 한 세션에서 다른 주제가 튀어나오면, 거기서 처리하지 말고 **해당 파일의
  "열린 질문"에 한 줄 적어 두고** 넘어갑니다.
