### 2-1. (1a) `T=0.5` 층 스윕 — 목표 ①을 끝낸다

`targets_dt0.5.json` 이 이미 있으므로 **타겟을 새로 만들 필요가 없습니다.**

**먼저 예산을 재세요.** 아래 "~7시간" 은 점 두 개(`L=2` 840 s, `L=3` 4,675 s)
외삽이라 믿을 게 못 됩니다. `(T=0.5, L)` 마다 1에폭만 돌려 초/에폭을 재고
곱하면 몇 분 만에 진짜 예산이 나옵니다.

```bash
free -g          # 프로세스당 ~1.6GB. 여유 없으면 하나씩

python scripts/run_pipeline.py --stages 3 --train te --set ansatz.n_layers=4 &
python scripts/run_pipeline.py --stages 3 --train te --set ansatz.n_layers=5 &
python scripts/run_pipeline.py --stages 3 --train te --set ansatz.n_layers=6 &
wait
```

절단은 `min_delta: 1e-7` 기본값 그대로 둡니다. **`final_delta` 와 `eps_trunc`
를 결과에 반드시 남기세요** — 깊은 층에서 절단이 처음으로 문제가 될 수 있고,
그때 구분할 근거가 그것뿐입니다.

**채점**은 `|0…0⟩` 이 아니라 **곱상태 평균**으로 합니다 (주장 문구가 "임의
곱상태"이고, `|0…0⟩` 단독 채점은 한때 틀린 결론을 만들었습니다):

```bash
python scripts/03g_state_averaged.py --n-states 24
```

새 결과 파일을 스크립트의 파일 목록(`main()` 안 `for fname, L in (...)`)에
추가한 뒤 돌리세요.

**이겨야 하는 값** (같은 2Q 의 grouped S2, 곱상태 평균 infidelity):

| 훈련 | 2Q | 이겨야 하는 값 |
|:--|--:|--:|
| `L=4` | 96 | **7.82e-4** |
| `L=6` | 144 | **1.52e-4** |

`L=3` 이 8.81e-4 였습니다. **판정:**

- 배수가 `L` 과 함께 **커지면** → 목표 ① 성립, 논문에 실을 곡선
- `L=3` 에서 정점 찍고 **작아지면** → 우위는 특정 깊이의 우연
- `L=4` 부터 지면 → **4×4 에서 목표 ①은 성립하지 않습니다.** 그대로 쓰는 것도
  결과입니다

### 2-2. (1b) QAOA 4×4 — 목표 ③ 경쟁자 표 완성

```bash
python scripts/03f_gs_competitors.py --lattice 4 --max-seconds 90
```

단열은 이미 `results/4x4/gs_adiabatic.json` 에 있고 (M=2~32), HVA ceiling 은
`statevector_pilot.json` 에 있습니다. **비어 있는 건 QAOA 뿐입니다.**

스크립트는 QAOA 를 **단열 스케줄로 초기화**한 뒤 무작위 재시작도 함께 씁니다.
무작위 초기화만 쓰면 `p=10` 이 `dE=0.87` 에 갇혀 QAOA 를 부당하게 깎게 됩니다
(4×4 에서 실측). 3×3 참고값: QAOA `p=10` 이 120 2Q 로 `dE=0.0065`, HVA `L=3`
가 36 2Q 로 `dE=0.0146` → 각도 묶음의 대가가 약 3.3배.

### 2-3. 무질서 메커니즘 — 값싸고 논문 가치가 큼

세 경로의 차이는 구조가 아니라 **회로가 흡수할 수 있는 무질서 정보량**입니다
(층당 자유 각도: 단열 0, QAOA 2, HVA 40). 그렇다면 **갭이 작을수록 HVA 우위가
커져야** 합니다 — 단열은 `T_A ~ 1/gap²` 로 불리해지니까요.

```bash
for s in 7 13 21 34 55 89; do
  python scripts/03f_gs_competitors.py --lattice 4 --seed $s --max-seconds 90
done
```

각 결과의 `ed_first_excited - ed_ground_energy` 대비 HVA/단열 배수를 그리세요.
**상관이 보이면 벤치마크 수치가 메커니즘 주장이 됩니다.**

### 2-4. p-VQD 타당성 (착수 전 설계 필요)

`T>0.5` 를 훈련 못 하는 이유는 정답지를 `T` 까지 고전 전파해야 하기 때문입니다.
p-VQD 는 `θ(t) → θ(t+dt)` 를 `max |⟨ψ(θ')|e^{-iH dt}|ψ(θ(t))⟩|²` 로 푸므로
전파할 회로가 `L+1` 층입니다. **항 수가 `T` 가 아니라 안수 깊이에만 의존**하고
비용이 `T` 에 선형입니다. 설계는 `01-scale-plan.md` 의 "돌파구 후보" 절.
